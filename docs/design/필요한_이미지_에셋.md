# 필요한 이미지 에셋 — Escale 여권

2026-11-13. 구현 원본: `mobile/src/data/stampCountries.ts`, `mobile/src/components/Stamp.tsx`.

## 사용 범위와 전달 규격

현재 코드는 국가별 이름·도시·귀국 날짜와 도형·잉크색 placeholder를 렌더링한다. 아래 이미지는 아직 생성·연결하지 않았다. 아래 목록은 현재 지원하는 모든 국가·지역 코드와 1:1로 대응하며, 세계 전체 국가 목록은 아니다. 시간대로 국가를 판별하지 못하면 도장을 발급하지 않고 설정 안내를 보여 준다.

소유자가 Higgsfield에서 생성할 아트는 투명 배경 PNG, 1024×1024, 중앙 단일 선화, 가장자리 12% 여백으로 전달한다. 국가명·도시·날짜·외곽 도형은 앱이 그리므로 이미지에는 글자·숫자·테두리를 넣지 않는다. 실제 출입국 관인, 정부 문장, 경쟁사 이미지·로고는 사용하지 않는다. 아래 색·모양은 **기존 구현의 식별 정보**이며 새 시각 디자인 지시가 아니다. 최종 스타일은 소유자의 별도 디자인 결정에 맞춘다.

최종 파일 경로는 `mobile/assets/stamps/<CODE>.png`. 현재 `Stamp`는 SVG placeholder를 사용하므로 파일만 넣어도 자동 연결되지는 않는다. 전달 후 정적 이미지 매핑을 추가하고 작은 크기에서도 식별되는지 확인한다.
