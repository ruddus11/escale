# Escale Stage 1 기능 검증 캡처

2026-11-13, iOS 26.4.1 / iPhone 17형 `Escale Feature QA` 독립 시뮬레이터. 로컬 개발 예시 여행을 사용했다. 이미지 생성·합성·리터치 없이 `simctl io screenshot` PNG 원본을 저장했다.

| 파일 | 확인한 내용 |
|---|---|
| `escale-stage1-plan.png` | 계획·공통 날짜·시간표·시간 미정 필터 진입 |
| `escale-stage1-today.png` | 오늘 날짜·JEV 상태·다음 일정·길찾기·완료 동작 진입 |
| `escale-stage1-money.png` | 예산·날짜별 지출·로컬 정산 진입 |
| `escale-stage1-passport.png` | 성공 완료 확인 후 대만 도장 1개·여행 종료일 표시 |

시뮬레이터에서 준호→나 50,220원 송금 **기록** 후 준호 차액 0원·민지 14,653원 잔여를 확인했다. 앱을 종료하고 다시 열어 송금 기록과 대만 도장 1개가 보존되는 것도 확인했다. 실제 송금은 하지 않았다.

캡처에는 병행 디자인 작업의 당시 UI가 포함돼 있다. 최종 디자인 승인이나 실기기·외부 서버·영수증 카메라·배포 검증의 증거로 사용하지 않는다. 초기 네 탭 캡처 뒤 현재 app.json으로 새 Escale.app을 빌드·설치·실행했다. 추가 `escale-stage1-passport-e2e.png`는 새 네이티브 바이너리에서 직접 생성한 여행→일정→오늘→지출→정산 완료→대한민국 도장 발급까지 이어간 결과다. 빌드 산출물의 표시 이름 Escale과 기존 bundle ID를 확인했다.
